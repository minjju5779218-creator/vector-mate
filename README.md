# VECTOR MATE

미리캔버스 일러스트 작업자를 위한 무료 브라우저 기반 이미지 → 실제 SVG 벡터 경로 변환 웹사이트입니다.

## 기능
- PNG/JPG/WEBP 업로드, 드래그 앤 드롭
- 색상 수(2~24), 곡선 디테일, 점 제거, 분석 해상도 조절
- 투명 배경(알파 임계값 128) 처리
- 실제 `<path>`로 구성된 SVG 생성 (이미지 embed 없음)
- 변환 전후 미리보기 및 SVG/PNG 다운로드
- 서버/API/빌드 도구 불필요

## GitHub Pages 무료 배포
1. GitHub에서 새 Public 리포지토리를 만듭니다 (예: `vector-mate`).
2. ZIP의 **vector-mate 폴더 안에 있는** `index.html`, `style.css`, `app.js`, `README.md`를 저장소 **최상위(root)** 에 업로드하고 Commit 합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch를 **main**, 폴더를 **/(root)** 로 설정한 후 Save 합니다.
5. 배포 후 `https://계정명.github.io/vector-mate/`로 접속합니다. 최초 배포에는 시간이 걸릴 수 있습니다.

## 로컬 실행
`index.html` 파일을 브라우저로 열면 됩니다. 서버가 필요 없습니다.

## 기술 및 품질 유의사항
- 이미지의 RGB 색상을 k-means 방식으로 단순화하고, 각 색상 면의 픽셀 경계를 따라 폴리곤 SVG path를 생성합니다.
- 실제 베지어 곡선 피팅이 아닌 **폴리곤 경로 단순화** 방식입니다. 디테일 조절은 경로 점 수를 줄입니다.
- 원본의 부드러운 반투명 가장자리, 그라데이션, 사진의 미세한 질감은 완전 재현되지 않습니다. 고대비 플랫 일러스트에 적합합니다.
- 작은 섬/구멍, 맞닿는 도형, 매우 복잡한 색상 경계에서는 아티팩트가 생길 수 있습니다.
- SVG가 실제 벡터라는 것과 미리캔버스 업로드 심사를 통과한다는 것은 별개입니다. 해당 플랫폼의 최신 규격을 확인하세요.
- 소유하거나 변환 권한이 있는 이미지만 이용하세요.
